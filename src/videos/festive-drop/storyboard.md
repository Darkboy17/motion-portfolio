# The Festive Edit — storyboard

A 22 s, 9:16 collection-drop reel for Loom & Lantern (a fictional label).
Bed: `pulse`, 120 BPM, so a beat is 0.5 s (15 frames). Bars 1–2 are hats only;
the kick lands on bar 3 (4 s), with the first garment. Times live in `timeline.ts`.
