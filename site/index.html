Where does a thrown ball land?

A quadratic equation answers three questions about one throw: when it lands, how high it goes, and whether it can reach a 15 m ledge.

  1. Model
  2. Land
  3. Peak
  4. Reach
  • The throw becomes the graph: the ground turns into the time axis and the ball's path into the curve.
  • Every number comes from three inputs. Change the launch speed in Remotion Studio and the whole video works itself out again.
  • The discriminant is a line sliding down the graph: no crossing, one touch, then two crossings as D changes sign.

What does a speedometer measure?

Speed is distance over time, and an instant has no time in it. The derivative resolves that, and a car makes it visible.

  1. Distance
  2. Average
  3. Instant
  4. Tangent
  5. Rule
  • The road runs beside the distance axis, so the car's place on the road is the height of the graph.
  • The secant's gap shrinks from 4 s to 0.01 s while a table records the average settling on 14.4 m/s.
  • A tangent slides along the curve and drives a live speedometer and the speed graph at the same time.

How does a game turret aim?

Two positions in, one angle out. Plain arctan gets it right on one side of the screen and backwards on the other; atan2 fixes it.

  1. Triangle
  2. Track
  3. The bug
  4. atan2
  5. In games
  • The bug is shown, not described: when the target crosses to the left, the turret turns red and aims the opposite way.
  • The code on screen changes from Math.atan to Math.atan2, the way a developer would meet the fix.
  • The homing missiles are a real steering simulation: atan2 plus a turn-rate limit, deterministic so every frame renders the same.

How it's built

The six pieces share one kit: design tokens, motion helpers and a set of components for video. A new explainer starts from parts that already look right together, and a change to the kit reaches every piece.

Motion
Eased, clamped, staggered entrances and quicker exits, all timed in seconds.
Text
Word-by-word reveals, and captions that also export as WebVTT.
Diagrams
SVG paths that draw themselves on, arrows, angles and labelled callouts.
Charts
Plots written in graph units, with axes, guides and tangents.
Maths
Equations built from spans, so one term can enter or light up on its own.
Code
Typed-in code with syntax colour and line focus.
Readouts
A gauge, counting numbers and a chapter bar for course modules.
Media
Sound placed on its frame, and Lottie files recoloured to the theme.
